# 10 · Worklog

One page per work session, newest at the top of the index below. A worklog
page is the minimum docs update for any piece of work. It records what was
done and points to the chapters that were updated, so the rest of the book
stays organised by topic while this chapter stays chronological.

File name: `YYYY-MM-DD-short-slug.md`. Several pages on one day are fine.

## Template

```markdown
# YYYY-MM-DD · Title

**Who:** name(s) (and "with Claude Code" or another agent if one helped)
**Branch / PR:** `branch-name`, PR link
**Goal:** one or two sentences.

## What was done
- ...

## Results
- numbers, links to `09-testing-and-results/` pages

## Decisions, facts, questions and bugs recorded
- D-NNN ..., Q-NNN ..., bugs-and-lessons page ..., knowledge page ...

## Left for next time
- ...
```
